## Relatando problemas

Encontrou um problema de parsing com a LSDB de um fornecedor específico?
Compartilhar uma amostra da base de dados no repositório correspondente é a
forma mais rápida de conseguir suporte — vários casos de IS-IS na página de
[Fornecedores suportados](reference/supported-vendors.md) estão esperando
exatamente por isso.
