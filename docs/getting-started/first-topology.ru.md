# Ваша первая топология

Этот пошаговый разбор проведёт вас от только что запущенного Topolograph до
первого проанализированного графа с помощью самого простого способа передачи
данных: **текстового файла**, скопированного с одного маршрутизатора.

!!! info "Вам понадобится"
    - Работающий экземпляр Topolograph ([установка через Docker](quickstart-docker.md)).
    - Доступ к **одному** маршрутизатору в области OSPF или IS-IS, которую вы
      хотите отобразить.

## 1. Получите LSDB с одного устройства

Поскольку вся область использует одну общую базу данных, собрать её нужно
только с одного маршрутизатора. Выберите команду для своей платформы - полная
таблица есть на странице [Поддерживаемые производители](../reference/supported-vendors.md).
Например:

=== "Cisco (OSPF)"

    ```
    show ip ospf database router
    show ip ospf database network
    show ip ospf database external
    ```

=== "Juniper (OSPF)"

    ```
    show ospf database router extensive | no-more
    show ospf database network extensive | no-more
    show ospf database external extensive | no-more
    ```

=== "FRRouting (OSPF)"

    ```
    show ip ospf database router
    show ip ospf database network
    show ip ospf database external
    ```

=== "Cisco (IS-IS)"

    ```
    show isis database detail
    ```

Сохраните вывод в обычный текстовый файл. Секции LSA 1 / 2 / 5 можно вставить
в один и тот же файл.

!!! tip "Более подробные линки (опционально)"
    Для FRRouting OSPF добавьте в тот же файл вывод команды
    `show ip ospf database opaque-area`, чтобы получить данные о пропускной
    способности, TE-метрике и административных группах. Это необязательно,
    граф строится и по одним LSA 1/2/5. См.
    [Traffic Engineering](../analysis/traffic-engineering.md).

## 2. Загрузите его

1. Откройте Topolograph по адресу `http://localhost:8080/`.
2. Выберите загрузку топологии и вставьте (или загрузите) свой текстовый файл.
3. Выберите **производителя** и **протокол**, соответствующие вашей выгрузке.
4. Отправьте - Topolograph разберёт LSDB и отобразит граф.

![Загрузка LSDB и получение графа](../assets/text_file_and_short_paths.gif)

Результат - это **снимок**: замороженная картина состояния сети в момент,
когда вы собрали базу данных. Весь анализ, который вы выполняете, происходит
на этом снимке, поэтому ничто из сделанного здесь не может повлиять на
действующую сеть.

## 3. Постройте первый путь

Когда граф уже на экране, выберите узел-источник и узел-назначение и
постройте между ними кратчайший путь. Topolograph подсветит путь и покажет
его суммарную стоимость.

![Построение дерева кратчайших путей](../assets/build-spt.gif)

Отсюда можно сразу:

- Увидеть **резервный путь**, который сеть использовала бы при отказе
  основного.
- **Выключить линк или узел** и посмотреть, как трафик перестроится.
- Открыть **Тепловую карту сети**, чтобы найти самые нагруженные и наименее
  защищённые линки.

Всё это описано в разделе [Анализ и визуализация](../analysis/index.md).
