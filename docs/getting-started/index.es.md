## La versión de 60 segundos

1. **Ejecute Topolograph** localmente con [Docker](quickstart-docker.md).
2. **Introduzca su topología** — [pegue un archivo de texto LSDB](../ingestion/text-file.md),
   o transmítala en vivo mediante una sesión de Watcher por [GRE](../ingestion/gre.md) o
   [BGP-LS](../ingestion/bgp-ls.md).
3. **Analícela** — [construya rutas, simule fallos, encuentre puntos débiles](../analysis/index.md).
4. **Monitoréela** — active un [Watcher](../monitoring/index.md) para capturar cada
   cambio y recibir alertas.
