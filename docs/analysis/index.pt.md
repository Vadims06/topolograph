# Análise e visualização

Uma vez que uma topologia está no Topolograph, ela se torna um modelo
interativo que você pode explorar e experimentar — com segurança, no seu
snapshot, nunca na rede em produção.

<div class="grid cards" markdown>

    ---

    Caminhos mais curtos, caminhos de backup primário e secundário, ECMP,

    [:octicons-arrow-right-24: Explore o grafo](visualizing.md)

-   :material-compare:{ .lg .middle } __Comparando estados da rede__

    ---

    Capture um snapshot da rede, faça uma mudança e veja exatamente o que
    difere entre dois pontos no tempo.

    [:octicons-arrow-right-24: Compare dois snapshots](comparing-states.md)

-   :material-file-code-outline:{ .lg .middle } __Topologias baseadas em YAML__

    ---

    Construa e visualize uma topologia arbitrária a partir de uma definição
    YAML — sem necessidade de rede ao vivo.

    [:octicons-arrow-right-24: Projete com YAML](yaml-topologies.md)
