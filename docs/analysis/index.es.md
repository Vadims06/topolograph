# Análisis y Visualización

Una vez que una topología está en Topolograph, se convierte en un modelo
interactivo que puede explorar y con el que puede experimentar — de forma
segura, sobre su instantánea, nunca sobre la red en vivo.

-   :material-compare:{ .lg .middle } __Comparación de estados de red__
