# 比较网络状态

您上传的每一份拓扑数据都是一个**快照**——网络在采集那一刻被冻结的状态。
Topolograph 会随时间保留您的快照，这意味着您可以将其中两个并排比较，*精确*
查看发生了哪些变化。

## 经典工作流程

1. **变更前快照。**上传当前的 LSDB（或让 [Watcher](../monitoring/index.md)
   自动持续生成快照）。
2. **进行变更。**例如，通过 route-map 和 prefix-list 将路由从 BGP 重分布到
   OSPF、调整链路度量，或添加新的邻接关系。
3. **变更后快照。**上传新的 LSDB。
4. **比较。**Topolograph 会高亮显示两个状态之间的差异。

由于每次上传都带有时间戳，您可以比较任意两个时间点——不仅限于连续的两次。

## 比较结果显示什么

- 两个状态之间新增或消失的**链路**。
- 现有链路上的**开销变化**。
- 新增或撤销的**网络/前缀**。
- 加入或离开拓扑的**节点**。

这将"我的变更是否达到了预期效果？"这个问题变成了一个可视化、可验证的答案——
而不必用肉眼比对原始的 `show` 命令输出。

## 与监控搭配使用

手动的变更前/后快照非常适合计划内变更。对于*计划外*的变更，
[Watcher](../monitoring/index.md) 会持续记录每一次状态转换，让您可以回溯查看
状态时间线，了解发生了什么变化以及何时发生——并通过 [ELK](../monitoring/elk-kibana.md)、
[Zabbix](../monitoring/zabbix.md) 或 [Slack](../monitoring/webhooks.md) 进行告警。
