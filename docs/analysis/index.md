# Analysis & Visualization

Once a topology is in Topolograph, it becomes an interactive model you can
explore and experiment with — safely, on your snapshot, never on the live
network.

<div class="grid cards" markdown>

-   :material-vector-polyline:{ .lg .middle } __Visualizing & Analyzing__

    ---

    [:octicons-arrow-right-24: Explore the graph](visualizing.md)

-   :material-compare:{ .lg .middle } __Comparing Network States__

    ---

    Snapshot the network, make a change, and see exactly what differs between
    two points in time.

    [:octicons-arrow-right-24: Diff two snapshots](comparing-states.md)

-   :material-file-code-outline:{ .lg .middle } __YAML-based Topologies__

    ---

    Build and visualize an arbitrary topology from a YAML definition — no live
    network required.

    [:octicons-arrow-right-24: Design with YAML](yaml-topologies.md)

-   :material-tune-variant:{ .lg .middle } __Traffic Engineering (TE)__

    ---

    Bring in bandwidth, TE metric and admin-group data, and reason about
    TE-aware paths.

    [:octicons-arrow-right-24: Work with TE attributes](traffic-engineering.md)
