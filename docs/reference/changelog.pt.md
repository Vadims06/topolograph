!!! note "Pareamento de compatibilidade"
    Funcionalidades do Watcher renderizadas no grafo do Topolograph dependem
    de uma versão mínima do Topolograph (OSPF Watcher → v2.27, IS-IS Watcher
    → v2.38). Mantenha o Topolograph e seus Watchers razoavelmente alinhados.
