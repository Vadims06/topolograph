# Registro de cambios

Topolograph y sus Watchers publican notas versión por versión en GitHub. En
lugar de duplicarlas aquí, esta página enlaza directamente a la fuente.

## Notas de release por componente

| Componente | Releases |
| --- | --- |
| Topolograph | <https://github.com/Vadims06/topolograph/releases> |
| OSPF Watcher | <https://github.com/Vadims06/ospfwatcher/releases> |
| IS-IS Watcher | <https://github.com/Vadims06/isiswatcher/releases> |
| Python SDK | <https://pypi.org/project/topolograph-sdk/> |
| MCP Server | <https://github.com/Vadims06/topolograph-mcp-server/releases> |

!!! note "Compatibilidad entre versiones"
    Las funciones del Watcher que se representan en el grafo de Topolograph
    dependen de una versión mínima de Topolograph (OSPF Watcher → v2.27,
    IS-IS Watcher → v2.38). Mantenga Topolograph y sus Watchers
    razonablemente alineados.
