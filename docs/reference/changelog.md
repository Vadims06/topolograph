!!! note "Compatibility pairing"
    Watcher features that render on the Topolograph graph depend on a minimum
    Topolograph version (OSPF Watcher → v2.27, IS-IS Watcher → v2.38). Keep
    Topolograph and your Watchers reasonably aligned.
