# Journal des modifications

Topolograph et ses Watchers publient chacun des notes de version sur
GitHub. Plutôt que de les dupliquer ici, cette page renvoie directement
vers la source.

## Notes de release par composant

| Composant | Releases |
| --- | --- |
| Topolograph | <https://github.com/Vadims06/topolograph/releases> |
| OSPF Watcher | <https://github.com/Vadims06/ospfwatcher/releases> |
| IS-IS Watcher | <https://github.com/Vadims06/isiswatcher/releases> |
| Python SDK | <https://pypi.org/project/topolograph-sdk/> |
| MCP Server | <https://github.com/Vadims06/topolograph-mcp-server/releases> |

!!! note "Compatibilité croisée des versions"
    Les fonctionnalités du Watcher qui s'affichent sur le graphe Topolograph
    dépendent d'une version minimale de Topolograph (OSPF Watcher → v2.27,
    IS-IS Watcher → v2.38). Gardez Topolograph et vos Watchers raisonnablement
    alignés.
