представлен список ссылок на последние release notes всех репозиториев
Topolograph.

!!! note "Парность совместимости"
    Функции Watcher-а, которые отображаются на графе Topolograph, зависят
    от минимальной версии Topolograph (OSPF Watcher → v2.27, IS-IS Watcher
    → v2.38). Держите Topolograph и ваши Watcher-ы в разумной синхронизации
    версий.
