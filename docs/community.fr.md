## Signaler un problème

Vous avez trouvé un problème de parsing avec la LSDB d'un fournisseur
particulier ? Partager un exemple de base de données sur le dépôt concerné
est le moyen le plus rapide d'obtenir un support ajouté — plusieurs cas
IS-IS sur la page [Fournisseurs pris en charge](reference/supported-vendors.md)
attendent exactement cela.
